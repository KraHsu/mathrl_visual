# Search the textbook

The navigation bar's local search indexes are generated separately for English
and Simplified Chinese. Search results stay in the current locale, so a query
never silently mixes translations.

<a id="how-to-search"></a>

## How to search

1. Open the search control in the top navigation (or press the shortcut shown
   by your browser).
2. Search for a word such as `Bellman`, `状态价值`, `SARSA`, or `\gamma`.
3. Follow the result and use the language switcher if you want the paired page.

The index is static and ships with the Pages artifact. It does not send a query
or a reading history to a server. The [learning map](./map) is a useful browse
fallback when you do not yet know a search term.

<a id="coverage"></a>

## What is indexed

- chapter lessons and checkpoints;
- flagship labs and their formula explanations;
- the appendix and bilingual glossary; and
- navigation, accessibility, source, and release pages.

Chinese searches retain algorithm names in Latin script and include the Chinese
terms from the glossary. English searches use the same stable content IDs when
you switch locale.
