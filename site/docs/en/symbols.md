# Symbols and terminology

Use the [full bilingual glossary](./learn/appendix/glossary) as the canonical
reference for notation, wording conventions, and search-friendly names.

<a id="quick-reference"></a>

## Quick reference

| Symbol | English | 简体中文 |
| --- | --- | --- |
| $s$ | state | 状态 |
| $a$ | action | 动作 |
| $r$ | reward | 奖励 |
| $G_t$ | return | 回报 |
| $\pi(a\mid s)$ | policy probability | 策略概率 |
| $V^\pi(s)$ | state value | 状态价值 |
| $Q^\pi(s,a)$ | action value | 动作价值 |
| $\gamma$ | discount factor | 折扣因子 |
| $\delta_t$ | temporal-difference error | 时间差分误差 |
| $\alpha$ | step size | 更新步长 |

The [learning map](./map) shows where each group of symbols first becomes
useful. If a page introduces a local convention, its audit table states it next
to the data rather than silently changing the global glossary.
