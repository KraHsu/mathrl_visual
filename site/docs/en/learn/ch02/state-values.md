# State values

A recorded episode answers, “What return occurred this time?” A state value answers, “What return should we expect, starting here and then following a specified policy?” These are different objects even when they use the same return definition.

<a id="learning-goals"></a>

## Learning goals

After this unit, you should be able to:

1. distinguish a sample return from its conditional expectation;
2. explain every condition implicit in $v_\pi(s)$;
3. handle terminal-state value without losing the reward for entering it; and
4. identify which changes can alter a state value.

<a id="return-random-variable"></a>

## A return is a random variable before the future occurs

Starting at time $t$, define the discounted return

$$
G_t=\sum_{k=0}^{T-t-1}\gamma^kR_{t+k+1}
$$

for an episode ending at time $T$. Before the environment and policy have generated the future, $G_t$ is a random variable. Its randomness can come from action sampling, stochastic transitions, stochastic rewards, or the initial state.

Once an episode is recorded, the same symbol has a realized numeric value for that sample. One unusually good or bad sample should not be confused with the expected result of repeatedly starting under the same conditions.

<a id="state-value-definition"></a>

## Condition on the current state and policy

The state-value function of policy $\pi$ is

$$
v_\pi(s)
=\mathbb E_\pi[G_t\mid S_t=s].
$$

This definition fixes four things:

- the current state is $s$;
- future actions are generated by policy $\pi$;
- future outcomes follow the environment model; and
- rewards are combined using the specified discount factor $\gamma$ and termination rule.

Therefore “the value of $s$” is incomplete language unless the policy and task specification are understood. The same state can have a different value under another policy, reward rule, transition model, discount factor, or terminal convention.

<a id="expectation-not-score"></a>

## Value is an expectation, not a label attached to a cell

Imagine a maintenance robot at a junction. Under a fixed inspection policy, half of its possible futures may finish quickly and half may require an expensive detour. The state value averages the discounted returns of all such futures with their probabilities. It is not necessarily equal to any return that can occur on a single run.

For example, if a state leads to return $4$ with probability $0.25$ and return $0$ with probability $0.75$, then

$$
v_\pi(s)=0.25(4)+0.75(0)=1.
$$

No run in this example has return $1$. Expectations summarize distributions; they do not have to be observable outcomes.

This also explains why a heatmap of values is not a map of immediate rewards. A state with zero immediate reward can have positive value because valuable outcomes remain reachable under the policy.

<a id="terminal-convention"></a>

## Count entry reward, then stop

For an episodic model, a convenient convention assigns terminal state $s_\mathrm{term}$ the value

$$
v_\pi(s_\mathrm{term})=0.
$$

This does **not** discard the reward for reaching the terminal state. That reward is $R_{t+1}$ on the transition into the terminal state. The zero says that there are no additional rewards after termination.

If entering a terminal state yields reward $5$, then the final one-step target is

$$
5+\gamma v_\pi(s_\mathrm{term})=5.
$$

Mixing “reward on entry” with “value after entry” is a frequent source of double counting.

<a id="value-dependencies"></a>

## What can change a value?

| Change | Can $v_\pi$ change? | Reason |
| --- | --- | --- |
| Take another sample with the same model and policy | No, not the mathematical expectation | Only the observed return changes |
| Change $\pi$ | Yes | Future action probabilities change |
| Change transition or reward rules | Yes | Future outcomes change |
| Change $\gamma$ | Usually | Later rewards receive different weight |
| Rename a state without changing its rules | No | A label alone has no mathematical effect |

The present chapter treats $\pi$ as fixed. It evaluates that policy; it does not search for an optimal policy, perform greedy improvement, or run value iteration.

<a id="self-check"></a>

## Self-check

1. Two episodes start from the same state under the same stochastic policy and produce returns $-2$ and $6$. Must either number equal $v_\pi(s)$?
2. Why can two policies give different values to the same physical state?
3. If the final transition pays $3$ and enters a terminal state of value zero, how much does that one-step target contribute before any earlier discounting?

::: details Check your answers
1. No. They are two samples from a return distribution; the state value is the distribution's conditional expectation.
2. The policies induce different probabilities over future actions and therefore over future returns.
3. It contributes $3+\gamma(0)=3$.
:::
