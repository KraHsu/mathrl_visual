# Policy improvement

Policy evaluation supplies more than a scorecard. Once $v_\pi$ is known, it can answer a counterfactual: what if the first action were $a$, followed by the original policy $\pi$? That counterfactual is $q_\pi(s,a)$, and it is the bridge from prediction to better decisions.

<a id="learning-goals"></a>

## Learning goals

After this unit, you should be able to:

1. distinguish the fixed-policy average $v_\pi(s)$ from each first-action value $q_\pi(s,a)$;
2. construct a policy greedy with respect to $q_\pi$;
3. state the policy-improvement guarantee with its assumptions; and
4. explain why one greedy improvement is not necessarily globally optimal.

<a id="queue-model"></a>

## An original queue model

Reuse the night document queue from the Chapter 2 checkpoint. There are two nonterminal states, $Q$ (queued) and $R$ (under review), plus terminal state $T$. The discount factor is $\gamma=0.5$. Each action has a deterministic one-step outcome:

| State | Action | Next state | Reward |
| --- | --- | --- | ---: |
| $Q$ | hold | $Q$ | $-1$ |
| $Q$ | forward | $R$ | $+1$ |
| $Q$ | inspect | $T$ | $+2$ |
| $R$ | return | $Q$ | $0$ |
| $R$ | recheck | $R$ | $-2$ |
| $R$ | submit | $T$ | $+4$ |

The original fixed policy uses probabilities $(0.5,0.5,0)$ at $Q$ and $(0.25,0.25,0.5)$ at $R$. Thus it never inspects at $Q$, but “inspect” remains an available action and can still be evaluated as a counterfactual.

<a id="fixed-policy-values"></a>

## Evaluate actions from the fixed-policy values

Chapter 2 gives

$$
v_\pi(Q)=0.6,
\qquad
v_\pi(R)=1.8,
\qquad
v_\pi(T)=0.
$$

For this deterministic outcome model,

$$
q_\pi(s,a)=r(s,a)+\gamma v_\pi(s'(s,a)).
$$

Therefore

$$
\begin{aligned}
q_\pi(Q,\text{hold})&=-1+0.5(0.6)=-0.7,\\
q_\pi(Q,\text{forward})&=1+0.5(1.8)=1.9,\\
q_\pi(Q,\text{inspect})&=2,
\end{aligned}
$$

and

$$
\begin{aligned}
q_\pi(R,\text{return})&=0+0.5(0.6)=0.3,\\
q_\pi(R,\text{recheck})&=-2+0.5(1.8)=-1.1,\\
q_\pi(R,\text{submit})&=4.
\end{aligned}
$$

As a consistency check, averaging these action values under the old policy recovers its state values:

$$
v_\pi(s)=\sum_a\pi(a\mid s)q_\pi(s,a).
$$

At $Q$, for example, $0.5(-0.7)+0.5(1.9)+0(2)=0.6$.

<a id="greedy-improvement"></a>

## Replace an average with a maximizing action

A deterministic greedy improvement chooses

$$
\pi'(s)\in\arg\max_a q_\pi(s,a).
$$

The queue calculations choose “inspect” at $Q$ and “submit” at $R$. More generally, because an average cannot exceed its largest term,

$$
q_\pi(s,\pi'(s))
=\max_a q_\pi(s,a)
\geq \sum_a\pi(a\mid s)q_\pi(s,a)
=v_\pi(s).
$$

Following $\pi'$ for the first action and $\pi$ thereafter is no worse than following $\pi$ immediately. Repeating that comparison through future decisions yields the policy-improvement conclusion

$$
v_{\pi'}(s)\geq v_\pi(s)
\quad\text{for every state }s
$$

in the finite discounted setting. A strict one-step inequality gives strict improvement wherever that advantage can affect the future return. Equality is allowed: ties can produce a different policy with the same value.

The theorem also permits a stochastic improved policy, provided it assigns probability only to maximizing actions. Mixing among equal maximizers preserves the same greedy backup.

<a id="local-not-global"></a>

## Greedy with respect to $v_\pi$ is not yet greedy with respect to $v_*$

In the queue, the first improved policy terminates immediately from both states, so

$$
v_{\pi'}(Q)=2,
\qquad
v_{\pi'}(R)=4.
$$

That is better than $(0.6,1.8)$, but evaluate the “forward” action again using the **new** continuation value:

$$
q_{\pi'}(Q,\text{forward})
=1+0.5v_{\pi'}(R)
=1+0.5(4)
=3.
$$

Now forwarding is better than inspecting for reward $2$. The first greedy change used continuation values generated by the old policy; improving future decisions can change which earlier action looks best. A second improvement chooses “forward” at $Q$ and “submit” at $R$, producing values $(3,4)$.

This example separates two statements:

- a greedy step with respect to $q_\pi$ is safely no worse than $\pi$;
- a single greedy step need not already maximize return over all policies.

<a id="self-check"></a>

## Self-check

Suppose a state $x$ has old-policy action values $(-0.2,1.4,1.4)$ and the policy average is $0.8$.

1. Which deterministic greedy policies are available at $x$?
2. May an improved policy randomize between actions two and three?
3. Does the tie imply that the optimal value function is non-unique?

::: details Check your answer
Either the second or third action is a deterministic greedy choice. Any probability mixture supported only on those two maximizing actions has the same one-step greedy value $1.4$. A tie can make the policy non-unique; it does not imply multiple optimal value functions. Under the discounted assumptions used here, the optimal value is the unique fixed point of $T_*$.
:::
