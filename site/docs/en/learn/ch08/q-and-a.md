# Chapter 8 Q&A

<a id="questions"></a>
## Questions

**Why can an unseen state change?** Its feature vector shares parameters with the visited state.

**Does a larger feature vector always improve accuracy?** No. It increases capacity and can increase variance or conditioning problems.

**Why keep a target network?** Holding $w_T$ fixed for a short interval makes the regression target less self-referential.
