# 搜索教材内容

顶部导航中的本地搜索索引分别为 English 和简体中文生成。结果只来自当前
语言，不会静默混合两个译文。

<a id="how-to-search"></a>

## 使用方法

1. 打开顶部导航的搜索控件（或使用浏览器显示的快捷键）。
2. 试着搜索 `Bellman`、`状态价值`、`SARSA` 或 `\gamma`。
3. 打开结果；需要另一种语言时使用语言切换器进入对应页面。

索引是静态 Pages 制品的一部分，不会把查询或阅读历史发送到服务器。不知道
关键词时，也可以先浏览[学习路线图](./map)。

<a id="coverage"></a>

## 索引范围

- 各章课程与检查点；
- 旗舰实验及其公式说明；
- 附录和中英双语术语表；
- 导航、无障碍、来源和发布页面。

中文搜索保留 Latin 字母算法名，并收录术语表中的中文词。切换语言后，英文
搜索仍使用同一组稳定内容 ID。

</noscript>
