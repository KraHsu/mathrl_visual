# 第六章检查点

先计算，再展开答案。请始终保留索引约定、噪声约定、采样协议以及有限/渐近范围；本章最常见的错误，是把记账错误伪装成收敛陈述。

::: info 原创伴读练习
任务、数字、问题和答案均为原创伴读材料。它们围绕第六章主题，不复制原文、图、示例、问题或代码。
:::

::: warning 有限证据不是定理
下面每一题都只涉及有限前缀。即使轨迹看起来完美，也不能证明几乎必然收敛。
:::

<a id="mean-update"></a>

## 1. 更新运行均值

从 $w_1=2$ 开始，使用精确平均步长 $a_k=1/(k+1)$ 处理观测 $x_2=8$ 和 $x_3=5$。计算 $w_2$ 与 $w_3$。

::: details 展开答案

$$
w_2=2+\frac12(8-2)=5,
\qquad
w_3=5+\frac13(5-5)=5.
$$

结果等于 $(2+8+5)/3$。分母对应更新后已纳入的观测数量；如果循环从零开始，不能直接把原始循环索引当分母。
:::

<a id="rm-update"></a>

## 2. 跟踪一次带噪 RM 更新

使用线性根 $g(w)=w-10$。当前 $w_k=12$，观测残差 $\widetilde g=1.5$，步长 $a_k=0.2$。更新量和下一个估计是多少？无噪声残差本应是多少？

::: details 展开答案

更新量为 $-a_k\widetilde g=-0.3$，所以 $w_{k+1}=11.7$。无噪声残差为 $g(12)=2$；观测噪声是 $1.5-2=-0.5$。带噪步骤仍指向根，但比无噪修正小。
:::

<a id="step-sums"></a>

## 3. 检查多项式调度

考虑 $a_k=0.8/k^p$。在 $p=0.25$、$p=0.75$、$p=1.25$ 中，哪个满足经典的两个渐近性质？

$$
\sum_k a_k=\infty,
\qquad
\sum_k a_k^2<\infty.
$$

::: details 展开答案

当 $1/2<p\leq1$ 时两者同时成立，因此 $p=0.75$ 合格。$p=0.25$ 时平方级数发散；$p=1.25$ 时普通步长级数收敛，可能让远处的迭代量冻结。浏览器中的有限级数只能近似这个分类。
:::

<a id="sgd-gradient"></a>

## 4. 分离一次 SGD 梯度

对平方损失，假设当前位置真实梯度为 $-2$，采样梯度为 $1$，步长 $a_k=0.1$。求噪声和更新增量。

::: details 展开答案

采样梯度噪声为 $\eta=1-(-2)=3$。更新增量为 $-0.1(1)=-0.1$。观测样本后再把步长应用到真实梯度，会得到另一个算法。
:::

<a id="batch-count"></a>

## 5. 计算工作量，而不只是迭代次数

有 $n=12$ 个样本。比较 10 次 BGD 更新、10 次 SGD 更新，以及批大小 $m=3$ 的 10 次小批量更新。若每个被选样本只计算一次梯度，每种模式进行了多少次样本梯度计算？

::: details 展开答案

BGD 进行 $10\times12=120$ 次；SGD 进行 $10\times1=10$ 次；小批量进行 $10\times3=30$ 次。如果小批量有放回采样，即使索引重复，计算次数仍为 30。因此相同更新次数不代表相同数据暴露量。
:::

<a id="theorem-scope"></a>

## 6. 判断这句话的范围

一份报告写道：“使用调和调度，一个种子在 200 次更新后达到 $|w-w^*|<10^{-3}$，因此 Robbins–Monro 收敛已被证明。”这句话有效吗？请改写得诚实。

::: details 展开答案

无效。可以改为：“在该配置和种子下，有限的 200 次轨迹达到指定容差；调和调度具有经典的渐近步长形状，但这次运行不证明几乎必然收敛。”报告还应包含根函数、噪声尺度、初值和停止规则。
:::

<a id="lab-challenge"></a>

## 7. 设计一次受控比较

在[随机逼近实验](/zh-Hans/labs/ch06-stochastic-approximation)中选择一个变量改变：噪声尺度、步长调度、根函数或批大小。为了让比较可解释，哪些字段必须保持不变？

::: details 展开答案

至少固定种子（或系统地比较多个种子）、目标/数据分布、初值、样本预算、容差和更新索引。记录改变的字段与采样协议。比较批大小时，还要同时报告更新索引和消费的样本数。
:::
