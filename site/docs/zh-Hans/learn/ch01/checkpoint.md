# 第一章综合检查点

这个检查点用同一个虚构配送任务串起第一章的概念。请先完成每道题，再展开参考答案。目标是检查模型内部是否一致，而不是寻找某种更好的行为。

::: info 原创伴读练习
本页的场景、数值、问题与答案均为本站原创伴读内容。它只使用原书涉及的主题范围，不复制原书正文、图、表、问题或代码。
:::

<a id="scenario"></a>

## 场景：档案馆配送车

一辆小车在博物馆的四个地点之间移动：

- 大厅 $L$；
- 走廊 $H$；
- 充电区 $C$；
- 档案馆 $A$。

回合结束前，小车能观察到当前位置、属于 $\{\text{电量充足},\text{低电量}\}$ 的电量类别，以及档案馆门当前是上锁还是解锁。电量类别会改变移动的可靠性，门的状态会改变小车能否进入 $A$。只要当前这些信息与动作已知，更早经过的地点就不会额外改变下一步规则。

可选动作依赖于当前位置，包括移动到相邻地点、等待，以及在 $C$ 充电。进入 $A$ 表示包裹送达，回合随即结束。电量耗尽会进入一个独立的失败状态，回合也会结束。到达 $C$ 本身不会结束回合。

<a id="state-sufficiency"></a>

## 1. 状态是否充分？

1. 只用位置表示状态是否充分？
2. 为每个非终止步骤给出一种充分状态表示。
3. 是否还必须保存上一个动作？
4. 假设档案馆门会在每个奇数步自动上锁，状态应该怎样修改？

::: details 查看参考答案
1. 不充分。在同一地点，不同电量类别会改变移动结果，不同门状态会改变 $A$ 是否可进入。
2. 一种充分表示是
   $$
   s=(\text{位置},\text{电量类别},\text{门状态}),
   $$
   再加上“送达档案馆”和“电量耗尽”两个显式终止状态。
3. 按题目给出的规则，不需要。当前三元组和动作已知后，上一个动作不再提供额外预测信息。
4. 奇偶相位会影响下一步，因此必须把它加入状态，例如
   $(\text{位置},\text{电量},\text{门状态},\text{步数奇偶})$。另一种办法是改写环境，使门的规则不再依赖隐藏时间。
:::

<a id="policy-vs-transition"></a>

## 2. 区分策略与状态转移

在状态 $s=(H,\text{电量充足},\text{已解锁})$，假设某策略满足

$$
\pi(\text{前往 }A\mid s)=0.60,
\quad
\pi(\text{前往 }C\mid s)=0.30,
\quad
\pi(\text{等待}\mid s)=0.10.
$$

动作“前往 $A$”被选中后，环境采用

$$
p(A\mid s,\text{前往 }A)=0.70,
\qquad
p(H\mid s,\text{前往 }A)=0.20,
\qquad
p(C\mid s,\text{前往 }A)=0.10.
$$

解释 $0.60$ 和 $0.70$ 各自表示什么。若其他动作都不可能在一步内到达 $A$，采用该策略时下一状态为 $A$ 的概率是多少？

::: details 查看参考答案
$0.60$ 属于智能体的策略：它是在状态 $s$ 选择“前往 $A$”的概率。$0.70$ 属于环境：在该动作已经选定之后，它表示实际到达 $A$ 的概率。

题设条件下，两个事件必须同时发生，因此

$$
\Pr(S_{t+1}=A\mid S_t=s)=0.60\times 0.70=0.42.
$$

随机决策规则与环境的随机响应是两个不同的不确定性来源。
:::

<a id="probability-normalization"></a>

## 3. 检查概率归一化

对固定状态—动作对，一行尚未完成的转移概率为

$$
p(A\mid s,a)=0.70,
\qquad
p(H\mid s,a)=0.20,
\qquad
p(C\mid s,a)=q.
$$

1. 求 $q$。
2. 另一行含有 $0.72$、$0.23$、$0.11$ 三个概率，它是否合法？
3. 每一行转移概率必须满足哪两个条件？

::: details 查看参考答案
1. 固定 $(s,a)$ 下的概率之和必须为 1，因此 $q=1-0.70-0.20=0.10$。
2. 不合法。第二行之和为 $1.06$，不是概率分布。模拟器应该拒绝它或要求从数据源修正，而不应静默接受。
3. 每个概率都必须非负，并且对全部可能下一状态求和为 1：
   $$
   p(s'\mid s,a)\ge 0,
   \qquad
   \sum_{s'\in\mathcal S}p(s'\mid s,a)=1.
   $$
:::

<a id="reward-and-return"></a>

## 4. 区分奖励与回报

从时刻 $t$ 开始，一个回合产生如下奖励：

| 步骤 | 事件 | 奖励 |
| --- | --- | ---: |
| $t\to t+1$ | 从 $H$ 移动到 $C$ | $R_{t+1}=-1$ |
| $t+1\to t+2$ | 在 $C$ 充电 | $R_{t+2}=-2$ |
| $t+2\to t+3$ | 从 $C$ 返回 $H$ | $R_{t+3}=-1$ |
| $t+3\to t+4$ | 进入 $A$ 并终止 | $R_{t+4}=+8$ |

1. 第一次转移后的即时奖励是多少？
2. 从时刻 $t$ 开始的无折扣回报是多少？
3. 当 $\gamma=0.5$ 时，手算折扣回报：
   $$
   G_t=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\gamma^3R_{t+4}.
   $$
4. 为什么不能只用最后一次奖励概括整条轨迹？

::: details 查看参考答案
第一次转移的即时奖励为 $R_{t+1}=-1$。无折扣回报为

$$
-1-2-1+8=4.
$$

当 $\gamma=0.5$ 时，

$$
\begin{aligned}
G_t
&=-1+0.5(-2)+0.5^2(-1)+0.5^3(8)\\
&=-1-1-0.25+1\\
&=-1.25.
\end{aligned}
$$

奖励只描述一次状态转移；回报则组合未来多次转移的奖励，而且折扣会改变较晚奖励的权重。因此，终止时的正奖励 $+8$ 本身不能决定无折扣回报或折扣回报。
:::

<a id="terminal-and-goal"></a>

## 5. 区分目标与终止状态

把下面每一项分类为“目标”“终止状态”“两者都是”或“两者都不是”：

1. 包裹送达且回合结束的档案馆 $A$；
2. 有助于完成配送但不会结束回合的充电区 $C$；
3. 回合结束但包裹没有送达的电量耗尽状态。

::: details 查看参考答案
- 档案馆 $A$ 既是目标，也是终止状态。
- 充电区 $C$ 可以是有用的中间目标，但按当前规则不是终止状态。
- 电量耗尽是终止状态，但不是目标。

“目标”描述任务希望达成的结果；“终止”描述回合在哪里停止。二者经常重合，但谁也不必然推出另一个。
:::

<a id="assemble-mdp"></a>

## 6. 组装 MDP

把每个建模问题与回答它的对象对应起来：

| 建模问题 | 需要给出的对象 |
| --- | --- |
| 任务中可能出现哪些情形？ | ？ |
| 每种情形下，小车可以请求什么？ | ？ |
| 发出请求后可能发生什么？ | ？ |
| 一次转移伴随什么即时反馈？ | ？ |
| 较晚的奖励怎样加权？ | ？ |
| 回合可以从哪里开始、在哪里结束？ | ？ |

最后判断：练习 2 中的策略属于环境动力学，还是施加在同一环境上的独立决策规则？

::: details 查看参考答案
该任务需要：

1. 状态空间 $\mathcal S$，包括充分的非终止状态和终止结果；
2. 依赖状态的动作集合 $\mathcal A(s)$；
3. 转移核 $p(s'\mid s,a)$；
4. 奖励规则，或等价的“下一状态与奖励”的联合描述；
5. 使用折扣回报时的折扣因子 $\gamma$；
6. 回合任务的初始状态规则和终止状态集合。

这些对象共同描述这里使用的有限序贯决策环境。策略 $\pi(a\mid s)$ 仍然是智能体一侧的独立决策规则。改变策略不必改变这个 MDP 的转移与奖励规则。
:::

<a id="completion-criteria"></a>

## 完成标准

不展开答案也能完成以下事项时，你就可以离开这个检查点：

- [ ] 解释为什么配送任务只记录位置会丢失预测下一步所需的信息；
- [ ] 判断一个概率属于 $\pi(a\mid s)$ 还是 $p(s'\mid s,a)$；
- [ ] 拒绝含有负概率或概率和不为 1 的转移行；
- [ ] 说清一次奖励与回报的区别；
- [ ] 在 $\gamma=0.5$ 时复算出 $G_t=-1.25$；
- [ ] 举出“是目标但不终止”或“终止但不是目标”的例子；
- [ ] 说出任务的状态、动作、转移、奖励、折扣、初始和终止部分。
