# 第八章总结

<a id="checklist"></a>
## 检查清单

- 特征向量把状态映射到共享参数。
- 线性 TD 使用特征向量作为梯度。
- 泛化既可能改善覆盖，也可能传播误差。
- SARSA 与 Q-learning 的区别体现在动作价值目标。
- 回放和延迟目标网络减少相关性，但引入新的节奏与诊断。

接着阅读[策略梯度方法](/zh-Hans/learn/ch09/)，学习直接表示动作的函数。
