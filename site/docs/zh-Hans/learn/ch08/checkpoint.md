# 第八章检查点

<a id="tasks"></a>
## 任务

1. 用独热特征运行一次 TD-Linear，指出发生变化的状态。
2. 切换到偏置 + 坐标，列出特征向量和更新范数。
3. 比较 Q-learning-Linear 与 Deep-Q，指出回放大小和目标同步次数。
4. 解释拟合有限回放损失为何不等于处处准确。
