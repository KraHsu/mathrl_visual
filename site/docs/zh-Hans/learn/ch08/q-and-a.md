# 第八章问答

<a id="questions"></a>
## 问题

**为什么未见状态也会变化？** 因为其特征向量与已访问状态共享参数。

**特征维度越大一定越准确吗？** 不一定；容量提高也可能带来方差和条件数问题。

**为什么保留目标网络？** 短时间固定 $w_T$ 可以让回归目标少一些自指。
