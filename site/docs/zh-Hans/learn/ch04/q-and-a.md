# 第四章问答

这些回答用于快速检查，不能替代章节推导。如果答案依赖容差、初始化或模型假设，这些依赖本身就是答案的一部分。

<a id="q1"></a>

## Value Iteration 保证找到最优价值吗？

在有限、奖励有界、折扣且模型精确已知的条件下，可以：它反复应用按 $\gamma$ 压缩的 $T_*$。在极限价值上读取最大动作集合即可得到最优策略（并列时可能有多个）。有限次运行返回的是近似或截断结果；保证针对极限序列（或明确的残差证书），不是针对四舍五入后的热图。

<a id="q2"></a>

## 每个 Value Iteration 向量都是状态价值吗？

不是。$v_k$ 是 $T_*$ 的迭代点。只有当它碰巧满足某个固定策略方程 $v_k=T_\pi v_k$ 时，才能称为该策略的状态价值。相应的 $q_k(s,a)$ 是针对迭代点的动作备份，不自动等于 $q_\pi$。

<a id="q3"></a>

## 为什么 Value Iteration 需要冻结副本？

声明的递推是同步的：$v_{k+1}$ 的每个状态都读取 $v_k$。复用刚写入的坐标会产生异步变体，有限运行轨迹和行为可能不同。它在适当条件下也可能收敛，但必须单独命名和测试。

<a id="q4"></a>

## Policy Iteration 有哪两个步骤？

先通过求解 $v_\pi=T_\pi v_\pi$（直接求解或达到声明的内层容差）评估当前策略，再选择使 $B_{v_\pi}(s,a)$ 最大的动作进行改进。只有策略或最大动作集合稳定时才停止，并且要单独报告评估状态。

<a id="q5"></a>

## 贪心改进会让每个状态都严格变好吗？

精确评估时，新策略逐状态不会更差。某个状态的严格优势不一定传播到每个状态，例如另一个状态可能永远到不了它。“不下降”定理不等于每个格子都严格上升。

<a id="q6"></a>

## 两个最优策略可以不同吗？

可以。如果某状态的两个动作备份相等，那么支持在这些最大动作上的任意分布都兼容同一个最优价值。确定性并列规则有助于复现，但不应抹掉数学上的并列集合。

<a id="q7"></a>

## “Truncated” 截断的是什么？

在 Truncated Policy Iteration 中，它指内层固定策略评估只做有限轮。不是删除稀有转移、裁剪奖励，也不是把外层工作上限伪装成已收敛。

<a id="q8"></a>

## 深度一就是 Value Iteration 吗？

只有在调度匹配时才是：内层更新必须从上一轮最优备份使用的向量开始，并在相应时刻构造策略。若初始化或沿用规则不同，深度一只能称为“类似 Value Iteration”。实验会记录这些选择，让口号可检验而不是凭想当然。

<a id="q9"></a>

## 内层深度该选多少？

没有普适答案。小深度更频繁地重新考虑策略，每轮工作较少；大深度得到更准确的策略价值，但可能把工作花在很快会改变的策略上。比较总模型备份数、内层残差和外层变化；只要记录规则，自适应深度也可以。

<a id="q10"></a>

## 更新量很小就等于收敛吗？

不等于。更新量 $\|v_{k+1}-v_k\|_\infty$ 只描述一步变化。Bellman 残差 $\|T_*v_k-v_k\|_\infty$ 检查不动点，策略稳定性检查外层决策规则，扫描上限只说明预算结束。

<a id="q11"></a>

## 有随机风时，智能体能看到滑移后再选动作吗？

不能。对一个请求动作，必须先平均所有实际结果：

$$
q_v(s,a)=\sum_{s',r}p(s',r\mid s,a)[r+\gamma v(s')]
$$

再比较请求动作。逐个结果取最大等于给了智能体额外信息，解决的是另一个问题。

<a id="q12"></a>

## 这些已经是模型无关强化学习算法了吗？

不是。本章规划器直接得到 $p(s',r\mid s,a)$ 并执行动态规划。基于模型的 RL 可能先从经验估计 $\hat p,\hat r$ 再规划；模型无关方法则不维护显式转移模型，而是估计价值或策略。GPI 图形相似，不会消除数据来源差异。

<a id="q13"></a>

## 终止状态如何处理？

按本伴读约定，进入终止状态时可以获得即时奖励，但其后续价值为零，也不创建动作行。若额外加入“终止后等待”动作，显示模型和策略计数都会改变。
