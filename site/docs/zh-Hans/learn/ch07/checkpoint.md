# 第七章检查点

<a id="tasks"></a>
## 任务

1. 在实验中关闭风扰并运行一次 TD(0)，手算目标。
2. 用同一种子切换 SARSA 与 Q-learning，指出不同的引导值。
3. 设 $n=3$，解释为什么第一次更新要等待多个转移。
4. 记录回合上限，判断最后轨迹是正常结束还是被截断。

完成后继续阅读[第八章](/zh-Hans/learn/ch08/)。
