# 第七章总结

<a id="checklist"></a>
## 检查清单

- TD(0) 根据一步 Bellman 样本更新状态价值。
- SARSA 使用行为策略采样的下一动作。
- n 步 SARSA 延迟备份，并暴露偏差/方差旋钮。
- Q-learning 使用下一动作最大值，是异策略方法。
- 每个有限轨迹都需要记录种子、上限、终止约定和目标。
