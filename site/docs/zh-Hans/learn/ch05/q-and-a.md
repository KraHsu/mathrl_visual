# 第五章问答

把下面的问题当作主动回忆练习。若答案依赖随机种子、时间范围、访问过滤器或策略族，应明确写出这些依赖。

::: info 原创伴读说明
问题与回答均为原创。它们沿用上游章节的主题范围，但不复制原书正文、图、示例或问题列表。
:::

<a id="q1"></a>

## 什么是 Monte Carlo 估计？

它是从随机样本进行估计。本章的样本是回合中的完整折扣回报，估计值是对归入某个状态或状态—动作键的回报求均值。它不是通过枚举转移模型得到的精确期望。

<a id="q2"></a>

## 样本均值与基于模型的均值有何不同？

基于模型的均值对所有可能结果按概率加权求和；样本均值对实际发生的结果求平均。前者对给定分布是精确的，后者存在统计误差，通常会在合适样本增多时缩小。

<a id="q3"></a>

## 为什么价值问题与均值估计有关？

对固定策略，$q_\pi(s,a)$ 是采取 $(s,a)$ 后折扣回报的期望。每个观察到的后缀回报都是这个随机变量的一个样本。因此估计 $q_\pi$ 就是一组逐键进行的均值估计问题。

<a id="q4"></a>

## MC Basic 改变了策略迭代的哪一步？

它用回合回报替代基于模型的策略评估，通常只记入回合初始状态—动作对，并对该对的重复回报求平均，再依据当前 $Q$ 估计改进策略。策略迭代类比描述的是调度，不会使估计变成精确值。

<a id="q5"></a>

## 什么是初始访问、首次访问和每次访问？

初始访问只记入回合起始对；首次访问记入回合中每个不同对的第一次出现；每次访问记入每一次出现。它们的样本数和相关性不同，因此结果必须报告使用了哪种过滤器。

<a id="q6"></a>

## 什么是探索性起点条件？

这是覆盖要求：每个合法状态—动作对都能以正概率作为回合起点，且长时间运行会为其提供足够起点样本。本实验用覆盖 75 个非终止对的确定性轮转来审计它；这是实验调度器，不等同于部署环境中的自然起点分布。

<a id="q7"></a>

## 为什么要反向计算回报？

在终止边界令 $G=0$，反复应用 $G\leftarrow R_{t+1}+\gamma G$，即可在线性时间得到所有后缀回报，避免重复求和重叠尾部，也能清楚区分自然终止与时间上限截断。

<a id="q8"></a>

## 每次访问一定会提高准确性吗？

不一定。它从每个回合使用更多观测，但重复后缀可能相关。更多记入样本在某些场景提供更多信息；有限样本误差还取决于方差、依赖、策略变化和覆盖，而不只是计数更大。

<a id="q9"></a>

## ε-greedy 为什么可以移除探索性起点？

柔性策略在每个访问状态给所有合法动作正概率。足够丰富的回合可以从普通起点发现许多状态—动作对，因此不必强制选择每个对作为起点。它移除的是强制选择，不保证覆盖快速或均匀。

<a id="q10"></a>

## 固定 ε 的策略是全局最优的吗？

通常准确的说法是：在数据充分时，它在指定的 ε-greedy 策略族内部最优。正 ε 会有意采取非贪心动作，所以策略不一定在所有策略中价值最大。若 ε 退火，策略族和数据分布也会随时间改变。

<a id="q11"></a>

## 一个回合能访问所有状态—动作对吗？

在连通性足够、回合足够长且策略柔性的环境中可能做到，但并非必然。一次成功轨迹只能证明可能性，不能保证所有种子或后续运行都覆盖；应报告实际计数。

<a id="q12"></a>

## 风扰动会让智能体看到结果后再选动作吗？

不会。智能体先从策略采样动作，环境再采样后继状态和奖励；MC 把实际结果纳入回报。规划器可以知道风分布，但模型无关更新不能针对每个已实现结果重新取最大值。

<a id="q13"></a>

## MC 界面中的“收敛”应是什么意思？

它应带有回合预算、种子、访问策略、终止规则和策略调度等限定。箭头稳定可能只是最近样本恰好一致，并不等于固定点残差或最优性证明。

<a id="q14"></a>

## 什么证据能让运行可复现？

保存算法模式、折扣因子、ε 调度、访问过滤器、起点协议、种子、回合上限、实际步与奖励以及更新顺序。用这些字段重放应复现有限轨迹。更换种子得到不同估计是另一场采样实验，不自动表示错误。
