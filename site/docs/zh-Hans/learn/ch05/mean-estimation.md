# 均值估计：小型的模型无关问题

把 Monte Carlo 控制还原成一个问题会更容易理解：不知道随机变量分布时，如何估计它的均值？状态价值和动作价值都是回报的均值，因此这个小问题包含了本章的统计核心。

::: info 原创伴读说明
下面的硬币、诊断和计算数字均为原创。它们借用上游单元的主题，但不复制原书正文、图、证明或示例。
:::

<a id="learning-goals"></a>

## 学习目标

完成本单元后，你应该能够：

1. 写出基于分布和基于样本的两种均值；
2. 不保存全部观测值而更新运行均值；
3. 解释独立同分布样本为何重要；
4. 说明回报估计能够、也不能够证明什么。

<a id="two-views"></a>

## 同一个问题的两种回答

设 $X$ 在有限集合中取值。若已知概率质量函数，期望是加权和：

$$
\mathbb E[X]=\sum_xp(x)x.
$$

若不知道概率质量函数，但有观测 $x_1,\ldots,x_n$，则使用样本平均：

$$
\bar X_n=\frac1n\sum_{i=1}^{n}x_i.
$$

前一个计算对给定模型是精确的；后一个是依赖观测值的估计器。如果不说明信息来源而把两个数字都叫“均值”，就会掩盖模型边界。

<a id="coin-example"></a>

## 一个可复现的硬币思考实验

把正面编码为 $+1$、反面编码为 $-1$。已知公平硬币模型时，

$$
\mathbb E[X]=0.5(1)+0.5(-1)=0.
$$

现在假设学习器看到序列

$$
(1,1,-1,1,-1,-1,1,-1).
$$

八次观测的估计为 $\bar X_8=0$。另一组八次投掷可能得到 $0.25$ 或 $-0.5$，即使底层均值没有改变。这个差异是采样误差，而不是硬币定义发生了变化的证据。

可以维护两个计数器做快速检查：

| 量 | 上述序列的值 |
| --- | ---: |
| 观测数 $n$ | 8 |
| 和 $\sum_i x_i$ | 0 |
| 均值 $\bar X_n$ | 0 |
| 离差平方和 $\sum_i(x_i-\bar X_n)^2$ | 8 |

最后一行可用于方差诊断，但不是另一个均值估计。

<a id="online-update"></a>

## 运行均值更新

不必保存全部回报。若 $m_n$ 是观测 $n$ 次后的均值，下一个样本为 $x_{n+1}$，则

$$
m_{n+1}=m_n+\frac{x_{n+1}-m_n}{n+1}.
$$

例如从 $m_0=0$ 开始，观测 $2$、$-1$、$4$ 后有

$$
m_1=2,
\quad m_2=2+\frac{-1-2}{2}=0.5,
\quad m_3=0.5+\frac{4-0.5}{3}=\frac53.
$$

最后结果与 $(2-1+4)/3=5/3$ 相同。这正是 MC 回报账本使用的数值模式：增加访问次数，再按计数的倒数让旧估计向新回报移动。

<a id="law-of-large-numbers"></a>

## 更多样本带来什么

对于方差有限的独立同分布样本，

$$
\mathbb E[\bar X_n]=\mathbb E[X],
\qquad
\operatorname{Var}(\bar X_n)=\frac{\operatorname{Var}(X)}{n}.
$$

因此估计器无偏，方差随 $n$ 缩小。标准差按 $1/\sqrt n$ 缩小，而不是 $1/n$：要把典型噪声减半，大约需要四倍的独立样本。

这是关于采样过程的陈述，不保证每个有限前缀都很接近。单条混合很慢的轨迹产生的回报可能高度相关；此时简单的 iid 方差公式只能作为参照，并不会自动成为置信区间。

<a id="mc-bridge"></a>

## 从随机变量到回报

固定一个策略和状态—动作对 $(s,a)$。每次访问都可能产生一个回报样本 $G_i(s,a)$。动作价值估计仍是同一个运行均值：

$$
\widehat q_n(s,a)=\frac1n\sum_{i=1}^{n}G_i(s,a).
$$

这里的随机变量是“这次访问之后的折扣未来奖励”。它的分布由策略、环境动力学、折扣因子和终止规则共同决定。MC 学习从回合估计它，而不是枚举 $p(s',r\mid s,a)$。

以下两条记账规则可以避免常见错误：

1. 只有当所选访问策略纳入该次访问时，才增加计数；
2. 使用该次访问之后的回报，而不是只有即时奖励。

如果计数为零，应显示“未访问”，而不是 $0$。已访问但回报为零，与没有数据是两件不同的事。

<a id="audit"></a>

## 均值估计审计

阅读 MC 轨迹时，可以询问：

| 审计问题 | 应要求的证据 |
| --- | --- |
| 随机变量是什么？ | 明确的回报定义与折扣因子 |
| 哪些观测进入了均值？ | 访问策略和计数 |
| 样本是否 iid？ | 回合生成假设或相关性说明 |
| 估计是否精确？ | 有限样本永远不是精确值；应显示不确定性或残差措辞 |
| 能否重放？ | 随机种子、配置和回合轨迹 |

[Monte Carlo 实验](/zh-Hans/labs/ch05-monte-carlo) 会在运行估计旁显示这些字段。只改变随机种子，就能看到不同样本路径产生不同的有限估计，同时环境定义保持不变。

<a id="check-yourself"></a>

## 自测

某个状态—动作对已经收到回报 $3$、$1$ 和 $-2$，当前均值为 $2/3$。第四个回报是 $5$。

计数变为四，新均值为

$$
\frac23+\frac{5-2/3}{4}=\frac32.
$$

如果第四个数字其实来自另一个状态—动作对，把它加入就属于记账错误，即使算术看起来仍然合理。MC 的正确性始于识别随机变量及其访问键。
