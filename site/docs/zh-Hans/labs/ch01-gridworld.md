# Grid World 概念实验

这个原创 4×4 场景把第一章的多个概念放进同一条可检查轨迹。所有计算都在浏览器内的 Dedicated Worker 中完成，数值逻辑来自 Rust 编译的 WebAssembly。

<GridWorldLab locale="zh-Hans" />

::: tip 风扰动引导
实验先从确定的无风基线开始。打开“转移”或“马尔可夫”视图，先读完平静情形的预测，再点击醒目的“开启 20% 风扰动并重置”。重置后切换到另一个视图：转移表会显示多个可能的实际动作，马尔可夫视图则解释为什么隐藏的风模式必须进入状态。使用文档种子 `5eed` 重置后请求“右、右、下、下”，再看轨迹：实际动作会稳定复现为“右、右、下、左”。两个视图都会提供这个按钮，因此可以从任一条教学路径开始对照。
:::

<a id="how-to-read"></a>

## 怎样阅读一次状态转移

每次点击动作后，按以下顺序解释结果：

1. **当前状态**是动作前的格子 $s_t$；
2. **计划动作**是你请求的 $a_t$；
3. 风可能产生不同的**实际动作**；
4. 环境根据实际动作得到下一状态 $s_{t+1}$；
5. 环境发出即时奖励 $r_{t+1}$；
6. 表格把奖励累加成回报，并按 $\gamma^t$ 计算折扣贡献。

本站的折扣回报使用

$$
G_0=\sum_{t=0}^{T-1}\gamma^t r_{t+1}.
$$

这里只计算给定轨迹，不进行策略学习，也不提前引入 Bellman 方程。

<a id="learning-views"></a>

## 八个视图，共用一个实时模型

上方选择器不是八个互不相关的演示。每个视图都读取或更新同一份语言中立实验状态：

| 视图 | 可以检查的问题 |
| --- | --- |
| 世界 | 智能体在哪里，可以请求哪些动作？ |
| 转移 | 完整的 $p(s',a_{\mathrm{实际}}\mid s,a_{\mathrm{计划}})$ 概率行是什么？ |
| 策略 | $\pi(\cdot\mid s)$ 是否构成概率分布，Rust 会采样哪个动作？ |
| 奖励 | 普通移动、碰撞、危险格和目标分别发出什么即时数值？ |
| 回报 | $\gamma^t$ 与 $r_{t+1}$ 怎样计入两种累计回报？ |
| 回合 | 目标会终止、零奖励吸收，还是允许交互继续？ |
| 马尔可夫 | 风模式未进入状态时，丢失了什么预测信息？ |
| 审计 | 当前转移、策略、折扣、奖励和特殊状态规则是否有效？ |

切换语言时会保留这份状态，并由同一个固定种子的 Rust 引擎重放计划动作。

## 观察任务

### 任务 A：动作不等于位移

保持风扰动为 0，在起点连续请求“向上”。解释为什么步数和回报改变了，而状态没有改变。

### 任务 B：奖励不等于回报

找到一条经过危险格但最终到达目标的路径。比较目标格的正奖励与整条轨迹的累计回报。一次正奖励不能抹去此前所有代价。

### 任务 C：复现随机转移

把风扰动改为 40%，记下种子和动作序列。使用相同种子重置后重复动作，再换一个种子比较。随机不代表无法复现。

### 任务 D：把策略与风分开

在“策略”视图中先归一化一个无效概率行，再把“向右”设为概率 1。分别在 0% 和 40% 风扰动下从策略采样。策略决定计划动作，风决定实际动作。

### 任务 E：审计状态充分性

打开“马尔可夫”视图，解释为什么同一个可见格子在隐藏的平静/阵风模式下会预测出不同结果，再给出修复状态所需的最小扩充。

### 任务 F：把目标与终止分开

在“回合”视图中，分别使用三种目标行为执行同一条右边缘路径。到达 $s_{15}$ 后再请求一次向左，比较动作是被拒绝、变成零奖励自环，还是移动到 $s_{14}$。

<a id="implementation-note"></a>

## 实现说明

- 环境：原创 4×4 Grid World；
- 起点：$s_0$；目标：$s_{15}$；危险格：$s_6,s_9$；
- 风扰动默认关闭，保证操作确定；“转移”和“马尔可夫”视图提供一键开启 20% 风扰动的引导实验；
- 默认普通移动奖励：$-0.04$；边界与危险：$-1$；目标：$+1$；四类数值均可编辑；
- 到达目标即结束回合；
- 转移分布、策略采样、奖励、累计回报与折扣回报由同一个 Rust 核心计算；
- 图形之外保留完整数值表，全部动作支持按钮与键盘。
