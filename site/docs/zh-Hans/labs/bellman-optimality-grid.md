# Bellman 最优性 Grid World 实验

这个实验把第一章的同一份 4×4 Grid World 转换为动作感知的 Bellman 最优性模型。Rust/Wasm 在 Worker 中枚举每个状态—请求动作的联合结果并执行数值备份；Vue 展示价值热图、动作账本、全部贪心箭头、残差和参数对照。

::: info 共享模型
本实验不使用另一个四状态微模型。它与第一章共享状态编号、边界、危险格、目标、奖励与风扰动语义，使“轨迹中发生什么”和“模型如何选择最优动作”可以逐项对应。
:::

<a id="experiment"></a>

## 实验目标

使用同一份模型完成四类观察：

1. 展开一个请求动作的全部随机结果，核对概率加权期望；
2. 比较五个请求动作的 $q_v(s,a)$，保留完整并列最大集合；
3. 从零向量同步应用 $T_*$，观察最优价值从目标向外传播；
4. 改变 $\gamma$、危险奖励或风扰动，定位策略变化来自哪一个动作备份。

<a id="model"></a>

## 默认共享 4×4 模型

状态按行优先编号：

```text
s0   s1   s2   s3
s4   s5   s6   s7
s8   s9   s10  s11
s12  s13  s14  s15
```

默认配置为：

| 字段 | 值 |
| --- | --- |
| 起点 | $s_0$ |
| 终止目标 | $s_{15}$，后续价值固定为 $0$ |
| 危险格 | $s_6,s_9$，进入时获得危险奖励但不终止 |
| 请求动作 | 上、右、下、左、等待 |
| 普通移动奖励 | $-0.04$ |
| 碰撞边界奖励 | $-1$，状态保持不变 |
| 进入危险格奖励 | $-1$ |
| 进入目标奖励 | $+1$，只在进入时计算一次 |
| 风扰动 | $0$，默认转移确定 |
| 折扣因子 | $\gamma=0.9$ |

目标价值为零不代表进入目标没有奖励。`进入目标 +1` 属于上一状态的动作结果；若再把 $v(s_{15})$ 当成 $1$，就会重复计算。

<a id="operator"></a>

## 实验实际计算的算子

对候选价值 $v$，每个请求动作先计算

$$
q_v(s,a)
=\sum_{s',r}p(s',r\mid s,a)
[r+\gamma v(s')].
$$

再计算

$$
(T_*v)(s)=\max_a q_v(s,a).
$$

开启风后，一个请求动作会有多个实际方向结果。最大值仍只在五个**请求动作**之间计算；实际滑移结果全部留在同一个期望求和中。界面中的动作账本应逐行列出结果概率、下一状态、奖励、旧价值、折扣后继价值与加权贡献。

<a id="first-sweep"></a>

## 从零向量开始的第一轮 golden

令 $v^{(0)}(s)=0$。第一轮只比较期望即时奖励。与目标相邻的 $s_{11}$ 和 $s_{14}$ 可以一步获得 $+1$；终止状态保持零；其他状态都至少能选择一次普通移动或等待，得到 $-0.04$，优于碰撞或进入危险格的 $-1$。

按 $s_0$ 到 $s_{15}$ 排列：

$$
v^{(1)}=
\begin{bmatrix}
-0.04&-0.04&-0.04&-0.04\\
-0.04&-0.04&-0.04&-0.04\\
-0.04&-0.04&-0.04&1\\
-0.04&-0.04&1&0
\end{bmatrix}.
$$

初始 Bellman 残差与第一轮最大绝对更新量都是 $1$。提交第一轮向量后，当前残差变成 $0.9$，因为目标价值还能继续向外传播一层。

第二轮是更强的同步性检查：

$$
v^{(2)}=
\begin{bmatrix}
-0.076&-0.076&-0.076&-0.076\\
-0.076&-0.076&-0.076&0.86\\
-0.076&-0.076&0.86&1\\
-0.076&0.86&1&0
\end{bmatrix}.
$$

例如 $s_{10}$ 的五个动作备份为

$$
(-1.036,\ 0.86,\ 0.86,\ -1.036,\ -0.076),
$$

所以“右”和“下”必须同时显示为贪心动作。

<a id="final-golden"></a>

## 默认模型的最终 golden

同步备份继续把目标价值向外传播。第六轮后得到不动点，残差历史为

$$
1,\ 0.9,\ 0.81,\ 0.729,\ 0.6561,\ 0.59049,\ 0.
$$

以下数值保留六位小数：

| 状态 | 第一轮 | $v_*$ | 全部贪心请求动作 |
| --- | ---: | ---: | --- |
| $s_0$ | $-0.04$ | $0.426686$ | 右、下 |
| $s_1$ | $-0.04$ | $0.518540$ | 右 |
| $s_2$ | $-0.04$ | $0.620600$ | 右 |
| $s_3$ | $-0.04$ | $0.734000$ | 下 |
| $s_4$ | $-0.04$ | $0.518540$ | 下 |
| $s_5$ | $-0.04$ | $0.426686$ | 上、左 |
| $s_6$（危险） | $-0.04$ | $0.734000$ | 右、下 |
| $s_7$ | $-0.04$ | $0.860000$ | 下 |
| $s_8$ | $-0.04$ | $0.620600$ | 下 |
| $s_9$（危险） | $-0.04$ | $0.734000$ | 右、下 |
| $s_{10}$ | $-0.04$ | $0.860000$ | 右、下 |
| $s_{11}$ | $1$ | $1$ | 下 |
| $s_{12}$ | $-0.04$ | $0.734000$ | 右 |
| $s_{13}$ | $-0.04$ | $0.860000$ | 右 |
| $s_{14}$ | $1$ | $1$ | 右 |
| $s_{15}$（终止） | $0$ | $0$ | 无 |

例如 $s_0$ 的最短安全路径需要五次普通奖励后进入目标，因此

$$
v_*(s_0)
=-0.04\sum_{t=0}^{4}0.9^t+0.9^5(1)
=0.426686.
$$

危险格的惩罚发生在**进入**它时。从 $s_6$ 已经出发时，向右或向下的普通移动并不会再次收取进入危险格的惩罚，所以它的价值可以是正的。

<a id="views"></a>

## 视图与数值替代

实验应从同一份 Worker 快照呈现：

- **价值与策略：**16 状态热图、确定性展示箭头与完整并列动作标签；
- **动作备份：**选中状态的五个 $q_v$、最佳与次佳差值，以及每个随机结果的期望账本；
- **传播：**当前轮数、前后价值、单轮最大更新和 Bellman 残差历史；
- **压缩：**相邻同步像之间的最大范数距离与一步 $\gamma$ 上界；
- **参数影响：**当前配置与对照配置的价值、动作集合和变化状态；
- **模型审计：**概率归一化、终止价值、有限奖励、$\gamma<1$ 与收敛/截断状态。

颜色、线宽和箭头不是唯一信息源；每个图形都必须有等价数值表和文字摘要。

<a id="tasks"></a>

## 引导任务 A：检查第一轮

1. 保持默认无风配置并重置到零向量。
2. 选中 $s_{11}$，比较向下与其他四个请求动作的即时备份。
3. 应用一次 $T_*$，核对 $s_{11}=1$、$s_{14}=1$、$s_{15}=0$，其余为 $-0.04$。
4. 确认这一轮只读取 $v^{(0)}$；若更新途中读取新值，就不再是同步备份。

## 引导任务 B：追踪一个并列

1. 运行到默认不动点并选择 $s_0$。
2. 展开“右”和“下”的动作账本。
3. 两者都应得到 $0.426686$，完整贪心集合为 `{右, 下}`。
4. 检查展示用固定 tie-break 没有从数值表中删掉另一个动作。

## 引导任务 C：审计危险奖励

1. 比较从 $s_5$ 进入 $s_6$ 与从 $s_6$ 离开时的奖励。
2. 前者收取进入危险格的 $-1$；后者按到达的普通格收取 $-0.04$。
3. 解释为什么 $s_5$ 的最优动作是上或左，而 $s_6$ 的价值仍为 $0.734$。

<a id="contraction-task"></a>

## 引导任务 D：观察压缩而不是假定等号

提交一轮同步备份后，记产生当前向量的最大更新量为

$$
d_k=\|v^{(k)}-v^{(k-1)}\|_\infty.
$$

因为 $v^{(k)}=T_*v^{(k-1)}$，当前向量的残差满足

$$
\begin{aligned}
\rho(v^{(k)})
&=\|T_*v^{(k)}-v^{(k)}\|_\infty\\
&=\|T_*v^{(k)}-T_*v^{(k-1)}\|_\infty\\
&\leq\gamma d_k.
\end{aligned}
$$

在默认模型中执行第一轮后，$d_1=1$，新残差为 $0.9$，恰好达到上界。继续逐轮核对；后续比率小于 $0.9$ 是正常结果。若最大更新量已经为零，则只报告残差也为零，不再进行除零比率。再把 $\gamma$ 改为 $0.5$，先预测新的上界再运行。

<a id="factors-task"></a>

## 引导任务 E：改变一个因素

每次只改一个参数，再与默认快照比较：

- 把 $\gamma$ 调低，观察远处状态值怎样下降；
- 加重危险奖励，检查哪些动作不再指向危险格；
- 开启 20% 风扰动，展开边界或危险格附近动作的四个实际方向结果；请求方向应从 $1$ 变为 $0.85$，其余方向各为 $0.05$。默认风扰动参考解的起点价值约为 $-0.108770$，目标仍为零。

不要只比较箭头。先核对转移概率和动作期望，再解释哪个 $q_v$ 排序发生变化。默认任务是终止型目标，因此给所有实际步奖励加同一常数不保证策略不变。

<a id="audit"></a>

## 模型与结果审计

一个可接受的运行必须满足：

1. 每个非终止状态—请求动作的结果概率非负且总和为一；
2. $s_{15}$ 的价值固定为零，进入目标奖励只计一次；
3. 所有奖励和价值都是有限数；
4. $0\leq\gamma<1$；
5. 每个非终止状态至少有一个贪心动作；
6. 残差按 $\|T_*v-v\|_\infty$ 计算；
7. “收敛”只在残差不高于容差时成立；达到扫描上限则显示“截断”；
8. 运行、重置或切换语言后，配置、轮数、价值、选中状态和视图一致恢复。

<a id="accessibility"></a>

## 键盘、屏幕阅读器与降级

所有状态和视图都必须可用键盘选择；热图使用可读的网格名称；SVG 提供本地化标题和描述；动态播报只报告开始、暂停、收敛、截断或错误等阶段，不逐轮淹没读屏器。

在减少动态效果偏好下，连续运行可以在 Worker 中批处理，但最终数值路径必须与单轮执行一致。组件加载失败时，本页上方的 golden 表、公式与任务仍构成完整的静态替代。

<a id="chapter-boundary"></a>

## 与第四章的算法边界

本实验反复应用 $T_*$，目的是验证 Bellman 最优方程的不动点和压缩性质。它可以提供单轮、运行、暂停与重置以便观察，但不在本章比较 Value Iteration、Policy Iteration 和 Truncated Policy Iteration 的伪代码、评估深度或计算代价；这些内容现在由[第四章](../learn/ch04/)负责。
